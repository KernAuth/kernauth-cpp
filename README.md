# KernAuth C++ SDK

Official client. Build with CMake and libsodium.

Pin the public key and key ID from the Developers page. Pass them with `--public-key` and `--key-id`. Do not download a different key at runtime.

Set `KERN_LICENSE_KEY` and `KERN_INSTALLATION_ID`, then run activate, validate, and deactivate. A patched binary can still skip the check.

Documentation: https://kernauth.apidog.io
